## 用户提供的 LM386 板

照片中有 3.5mm 音频输入插孔、音量旋钮、两个电源端和两个“喇叭”输出端。它本身没有数字接口，也不是能直接接 ADC 的 3.3V 偏置输出模块。

手机连接 LM386 的 3.5mm 输入；供电使用稳定 5V 并按板上电源正负丝印连接。不要按翻转照片后的左右位置猜端子。虽然商品图标“3～12V”，TI 对常见 LM386 的推荐供电从 4V 起；这里不采用 STM32 的 3V3 给功放供电。功放大电流回路尽量避开 ADC 模拟地回流路径。

[TI 数据手册](https://www.ti.com/lit/ds/symlink/lm386.pdf)中芯片输出有约电源一半的直流偏置；成品板可能经输出电容隔直。因此仅凭模块型号不能认定喇叭输出既无负压又小于 3.3V。

## A 板：手机音频采集

保留你们目前的手机→LM386 接法时：

手机音频 → LM386 输入插孔 → LM386 喇叭输出 → 衰减 → 隔直 → 1.65V 偏置及低通 → A板 PA1。

LM386 喇叭输出不能直接接 PA1。下面是用于初调的无源调理示例，正式接入前需测量波形：

1. 先断电测量“喇叭 −”与“电源 −”是否导通。确认是同一地后，电源 − 和 STM32 GND 共地；若不导通，先确认模块电路，不能把未知桥接输出的一端直接接地。
2. 用一只额外的 10kΩ 电位器作为衰减：两端接已确认的喇叭信号与信号地，滑动端从接地位置起调。
3. 滑动端 → 1µF 无极性隔直电容 → 3.3kΩ 电阻 → 节点 X → PA1。
4. 节点 X 经 10kΩ 接 STM32 3V3，另经 10kΩ 接 STM32 GND，提供约 1.65V 偏置。
5. 节点 X 经 22nF 电容接 GND，配合源阻抗形成约数 kHz 的一级低通；截止频率随电位器位置变化。这是简易人声联调电路，不是高阶抗混叠滤波器。
6. 未接 PA1 时先上电测 X：静音约 1.65V；手机及 LM386 从小音量开始，逐渐调衰减，先取约 1Vpp，保证所有瞬态均在 0～3.3V 后再接 PA1。更改功放供电、音量或音源后需重新检查，固定电阻或电位器不能自动限幅。

软件中的 ADC 校准仅校准 ADC 自身，不会把外部负电压或过压变安全。8kHz 采样宜输入约 3kHz 以下的人声；手机音乐的高频成分需更充分的模拟低通才能避免混叠。

更简单的接法是手机耳机/线路输出直接经过上述衰减、隔直、偏置和低通进 PA1，省去发射侧 LM386，把 LM386 用在接收侧播放。若取手机立体声，只取一个声道，或两个声道分别串电阻后合成单声道，不能直接短接 L/R。

## A 板：发射 LED

| 起点 | 终点 |
|---|---|
| A 板 PA2（A2） | 1kΩ → S8050 基极 B |
| S8050 发射极 E | A 板 GND |
| S8050 集电极 C | LED 阴极 |
| LED 阳极 | 限流电阻 → 5V |

普通小功率 LED 可从 330Ω 限流试起，最终按 LED 正向压降/额定电流确定。S8050 的 B/C/E 实物脚序按实际器件确认。大功率 LED 需要合适的恒流及开关驱动，不能照搬小灯电路。PA2 与 5V 不直接连接。

USART2 8N1：高电平亮灯，低电平灭灯；SEND 空闲亮灯是正常的。115200baud 的每位约 8.68µs，肉眼无法判断数据内容。

## B 板：光接收

光敏器件 → 适当带宽的放大电路 → 比较器 → B 板 PA3（A3）。

- 输出必须为 0～3.3V，且亮灯时 PA3 高、灭灯时 PA3 低。
- 开集电极输出需上拉到 3.3V，并确认上升沿速度足够。
- 若极性反了，交换比较器同相/反相输入或加硬件反相器。本版不能用软件 OOK_RX_INVERTED 修正 UART 帧极性。
- 旧 1000bit/s 接收前端不一定能跟上新版速率，需要用示波器确认 PA3 方波。
- 接收模块电源按其型号连接，接收模块 GND 接 B 板 GND。

## B 板：DAC 到功放播放

B 板 PA4（A4） → 1kΩ → 节点 Y；Y 经 47nF 接 B 板 GND；Y 再经 1µF 无极性隔直电容接播放功放的音频输入。

功放电源负端与 B 板 GND 共地，功放“喇叭”端只接喇叭。PA4 不接喇叭端，不直接接喇叭。

如果接收侧也使用照片中这块 LM386：用音频线接它的 3.5mm 输入，选一个输入声道；功放供稳定 5V，音量从最小调起。PA4 静音电压约 1.65V，隔直后才送入地参考的功放输入。功放增益较高，需减小音量避免削顶。

保留发射侧 LM386 时，接收侧还需一块独立功放；若只有一块，可以把它放在接收侧，手机输出直接调理后送 A 板 PA1。

## 两板共同外围

| 外设 | 本机引脚 |
|---|---|
| OLED SCL / SDA | PB8 / PB9 |
| OLED VCC / GND | 3V3 / GND，模块需支持 3.3V |
| K1 模式 | PB1 → 按键 → GND |
| K2 方向 | PB0 → 按键 → GND |
| K3 文字发送/音频开始停止 | PA5 → 按键 → GND |
| K4 停止回文字并清屏 | PC0 → 按键 → GND |

使用外接按键；不要把 RST、BOOT0 当作这些功能键。两端独立 USB 供电时无需互连地线，光是两板之间的信息通道。

## 使用

两端烧录新版固件。先 TEXT 模式验证 HELLO，随后两端 K1 到 VOICE。A 板 K2 到 SEND，B 板保持 LISTEN；A 板 K3 开始采样手机音频，B 板收到三包有效语音后自动播放。A 板再按 K3 停止；K4 停止并回到文字模式。

电路数值为联调示例，尚未在用户实物上测量；最终以电压、波形、误码率和听音结果调整。
